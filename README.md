# Asking the World

Project website: https://asking-the-world.github.io/

Paper: https://arxiv.org/abs/2609.39135

A static Coming Soon page with author information checked against arXiv v1. Layout follows the PhysMind project page. Shared authors use the same personal-page links.

## Local preview

Run `python -m http.server 8000` in this directory and open http://localhost:8000/.

## GitHub Pages

In Settings → Pages, choose Deploy from a branch, main, / (root).
